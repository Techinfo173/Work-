PROMPT 4 — Patrol, Investigate, vision, hearing
============================================================

This is a follow-up to changes already made. Don't recreate or remove anything that already exists in the project. Only add the new functionality described below. Read the current state of the files first.

Implement these enemy states with a yuka state machine. Each state plays the right animation clip with the same cross-fade weight blending system already used for the player weapon (never stop locomotion clips, just shift weights).

- Patrol: pick a random navmesh point within 15 units, path via `Pathfinding.findPath()`, walk at 2.5 u/s. On arrival, idle for 1–3 seconds, then pick a new point. Plays `walk` clip while moving, `idle` when stopped.
- Investigate: go to a target position passed in via the noise system. After arriving, look around for 2 seconds, then return to Patrol. Plays `walk`.

Vision: each frame, check if the player is in the enemy's 90° forward cone (dot product > 0.5), within 25 units, and not blocked by a BVH raycast from enemy chest to player camera. If all three pass, set the enemy's state to "chase target" (we'll implement Chase in the next prompt) and remember the player's position.

Hearing: when the player fires, broadcast a noise event with the player's world position and radius 30. Any enemy currently in Patrol within that radius transitions to Investigate, targeting the player's position.

Performance: skip enemy AI ticks if the enemy is more than 50 units from the player (freeze in place). On mobile, run AI updates every other frame. Only the 3 closest enemies do vision raycasts each frame; the rest cycle round-robin.

PROMPT 5 — Chase, Attack, Dead, damage
============================================================

This is a follow-up to changes already made. Don't recreate or remove anything that already exists in the project. Only add the new functionality described below. Read the current state of the files first.

Add three more states to complete the enemy AI:

- Chase: triggered when an enemy sees the player. Path to the player at 5 u/s, repath every 0.5 seconds. Plays `run`. When within 12 units AND line of sight is clear, transition to Attack. If sight is lost, stay in Chase for 3 seconds of "memory" then drop to Investigate at the last known position.
- Attack: stop moving, face the player. Fire a hitscan from the enemy's chest toward the player every 1.0–1.5 seconds (randomized). If the hitscan hits the player, deduct 8–15 HP. Use the `fire_up` clip if the player's Y is more than 2 units above the enemy, otherwise `fire`. If the player gets within 2 units, switch to melee: play `melee` clip, deduct 25 HP, 1-second cooldown. When out of attack range, return to Chase.
- Dead: disable AI, freeze the mixer on the current frame, tip the model by rotating its Z axis 90° over 0.5 seconds, fade the model out, and remove it from the scene after 5 seconds.

Damage to enemies: the player's existing hitscan now also raycasts against an array of enemy collider meshes. On hit, deduct from enemy HP (60 max), apply a brief stagger (push model back 0.1u over 0.15s). When HP hits 0, transition the enemy to Dead and increment the player's hits counter (only on confirmed kills).

When the locomotion master clip transitions to fire/melee/jump_attack, fade the locomotion layer master weight to 0 over 120ms, restore over 150ms when the overlay finishes.
